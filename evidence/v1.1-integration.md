## 7. 残留与未验证（如实声明）

1. **`main.ts` 的 `syncAccount` 编排**没有集成测试：只有它调用的 store 接缝被单测覆盖（`main.test.ts` 3 tests）。跨「适配器 → 规则分类 → 抽取 → 落库」的整链仍由 smoke 的间接路径与单测拼成，非端到端。
2. **Graph 个人账号 / 本地 Exchange 真实环境**只以手工清单存在（AC-08），本机不可执行；本轮未做真实收发。
3. **签名/显示名 UI 编辑器（T69）已落地**：team 记录 `T69.status=completed`，`SettingsPage.tsx` 含 `IdentitySnapshot` 编辑器；本轮未新增其 UI 自动化测试。
4. **跨重启的发送幂等不持久化**：`routes/send.ts` 的 `ledger` 是进程内 Map，进程重启后同一 `idempotencyKey` 不能去重。本轮未改动此设计（不在 T39 写域）。
5. **smoke 未覆盖的成功路径**：文件夹快照拉取成功、附件下载成功、发信成功（需真实/mock 服务器）；已由单测 fake transport 覆盖，见 §2 末。
6. **AC-02 / AC-11 / AC-28 的 UI 交互**：向导逐步跳过、停输 3 秒自动保存、规则树拖拽交互都没有浏览器级自动化，判为「部分」。
